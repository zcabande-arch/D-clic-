## 4. Réponses prêtes pour la messagerie

**« Mon code ne marche pas »**
> Vérifie qu'il n'y a pas d'espace en trop (les tirets et majuscules n'ont pas d'importance). Sur iPhone, entre-le dans l'app ouverte depuis l'icône de l'écran d'accueil, pas dans Safari. Si ça bloque encore, envoie-moi une capture d'écran.

**« J'ai changé de téléphone »**
> Sur l'ancien : Réglages (en haut à gauche) › Télécharger une sauvegarde. Sur le nouveau : ouvre ton lien, entre ton code, puis « J'ai une sauvegarde à restaurer ».

**« Je n'arrive pas à télécharger les fichiers »**
> Ouvre Etsy dans Safari ou Chrome (pas dans l'app Etsy), connecte-toi, puis Achats et avis › Télécharger les fichiers.

**« Je peux voir la démo avant ? »**
> Bien sûr : https://zcabande-arch.github.io/D-clic-/phase/?demo (données d'exemple, l'app complète s'ouvre avec le code reçu après l'achat).
